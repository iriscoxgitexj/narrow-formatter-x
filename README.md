# narrow-formatter-x

Rewriting small tools for developers in my spare time

周末做的小玩意


## 用法

```bash
cat data.txt | bash run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/stonetwo/narrow-formatter-x.git
cd narrow-formatter-x
chmod +x run.sh
```
